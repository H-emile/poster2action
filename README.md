# 一图成行 Poster2Action · 校样台原型

把一张静态活动海报，变成**每条信息都能倒查回原图位置**、**能看出哪里不确定**、**确认后能直接行动**的活动页。

这是「给海报装按钮」的可运行版本：校样台核对信息 → 圈出图上能点的地方 → 发出去（活海报 / 文字版）：校样台确认之后能生成一页手机活动页，带日历、导航、二维码分享，扫码打开的就是那一页。

## 怎么跑

```powershell
cd poster2action
npm install                     # 首次
npm run ocr:assets              # 首次：拉本机 OCR 的中文/英文语言包与 wasm（约 37MB，不进 git）
npm run dev                     # http://localhost:5180
```

不跑 `npm run ocr:assets` 也能启动，只是「本机 OCR 抄字」那个按钮会提示先去拉资源。

- 第一次 `dev` 会先跑 `scripts/gen-posters.mjs` 生成 10 张示例海报（`public/posters/*.svg`）和它们的字段坐标（`src/lib/samples/fixtures.json`）。
- **这台机器上必须带 `--configLoader native`**（已写进 `package.json`）。Vite 8 默认打包配置时会在受限环境下 `spawn EPERM`；脚本里已经绕开，正常 `npm run dev` 即可。
- 其他命令：`npm run check`（数据层 + 10 张陷阱断言）、`npm run typecheck`、`npm run build`（产物 `dist/`，`base: './'`）。

## 界面上能做的事

| 位置 | 动作 | 结果 |
| - | - | - |
| 左栏 10 张海报 | 点任意一张 | 换成那张的校样 |
| 中栏海报 | 点虚线框 | 框被钉住（实线+青色），右栏对应行亮起，并滚动到它 |
| 中栏海报 | 点已钉住的框 | 直接进入那一行编辑 |
| 右栏每一行 | 点「原图」 | 海报滚到该字段位置并高亮，浮出「字段名 + 看不看得清」 |
| 右栏每一行 | 悬停行 | 海报上对应该框提亮，其余变淡 |
| 右栏每一行 | 改值 | 立刻重算问题；出现「已手改 · 原值 · 撤销」 |
| 右栏问题卡 | 点卡片 / 「定位到…」 | 跳到对应字段并聚焦 |
| 底部 | 确认 | 还有问题时需**再点一次**才确认（防手滑）；确认后记录耗时与改动次数 |
| 顶部 | 适应 / 100% / 200% + 框线开关 | 缩放看小字；关掉框线只看原图 |

所有改动静默存在 localStorage，刷新不丢；换海报会保留每张的进度。

## 预置的 10 张陷阱（`npm run check` 会逐条断言）

| 海报 | 埋的坑 | 应该被拦成 |
| - | - | - |
| p01 余震 | 展期 10/24–11/15 + 每周二至周日 | 跨天/展期说明、年份推断 |
| p02 当街道开始说话 | 显式写 2026.11.07 | 不推断年份 |
| p03 午夜放映 | 11/13 通宵连映，散场 01:30 | 跨天说明 |
| p04 秋日手作市集 | 门票待定、10/31→11/1 跨天、摊位招募扫码 | 价格待定、跨天 |
| p05 独立音乐社 | 每周六、首次 10/31、写了「不用报名」 | 重复活动说明，且**不**报缺少报名链接 |
| p06 空的房间 | 「11月8日 周六」，实际是周日 | **必须处理**：日历冲突 |
| p07 设计学院 VS 计算机 | 只有「东区 田径场 足球场」，没有地址 | 建议核对：地址不可导航 |
| p08 笔记作为方法 | 2026.11.21 + 报名要跑公众号 | 建议核对：提到报名但没有链接 |
| p09 SWAP DAY | 没写年份 + 摆摊群报名 | 年份推断 + 报名无链接 |
| p10 HACK CAMPUS | 28–29 两天 + 正文带 `[where]` 装饰标签 | 跨天说明，标签被清掉 |

p06 之所以是默认打开的那张：它一进来就有 1 个必须处理，可以直接看拦截效果。

## 传自己的海报（P4）

1. 左栏底部「我的海报」→ **上传一张海报**，或者直接把图片文件拖进页面。
2. 上传的文档一开始是空的——**没有任何字段被自动填过**，标题栏和右栏顶上的引导卡都会明说。急的话直接点「从『活动名称』开始，带我一项一项圈」，它会带你一圈到底：圈完一项自动跳到下一个空的字段。
3. 每个字段右边有「框选原文」：点它，然后在海报上按住、从文字左上角拖到右下角，松手就定住。框里会显示你刚才圈的像素大小，方便确认框准了。
4. 松手后光标直接进那一行的输入框，照着框里的字打进去；这个字段的可信度默认记「不太确定」，看得清就点一下那个小标签改成「看得清」。
5. 框好的字段能「点回原图」；关掉浏览器再回来，原图从 IndexedDB 取回，框和字都还在。

图片存在 IndexedDB（localStorage 装不下手机照片），字段存 localStorage；不支持 IndexedDB 的浏览器会提示「刷新后要重新上传」。

## 抄字（本机 OCR，免费离线）

上传海报后右栏有「让机器先抄一遍」：

- **用本机 OCR 抄字（免费 · 离线）**：tesseract.js 在浏览器里跑，不联网、不要 key、海报不出本机。跑完列出每一行，点一行就复制，圈住哪块粘到哪一项。
- 语言包和 wasm 放在 `public/`（中文 19MB + 英文 10MB），由 `npm run ocr:assets` 从 `node_modules` 与 [tessdata.projectnaptha.com](https://tessdata.projectnaptha.com/4.0.0/) 拉下来；它们不进 git，所以仓库只有几百 KB 的代码与海报。
- 它只抄字、**不给位置**：位置永远是人圈出来的——这是「点回原图」这个卖点的前提。
- 艺术字标题、竖排、花体会读错（实测「午夜放映」读不出、`01:30` 读成 `81:30`）。所以它是「省手打」的辅助，不是「替你读懂海报」的魔法。

## 可选：让视觉模型先读一遍

默认不接任何模型（手动圈框那条路一直可用）。想用模型：

```powershell
# poster2action/.env.local（已在 .gitignore，别提交）
SILICONFLOW_API_KEY=sk-...
VISION_MODEL=deepseek-ai/DeepSeek-OCR   # 或 Qwen/Qwen3-VL-8B-Instruct
VISION_MOCK=0                            # 没额度/mock 演示时改成 1
```

模型按名字分红给两条路：

- **纯 OCR 模型**（名字带 `ocr`，如 `deepseek-ai/DeepSeek-OCR`）：把整页文字抄成一行一条，**不给位置**。右栏列出这些行，点一行就复制；位置还是你圈——它只解决「打中文慢」。
- **视觉问答模型**（如 `Qwen/Qwen3-VL-8B-Instruct`）：直接读成字段 + 原文片段 + 位置，填进字段并画框，每项标「模型读的」。

`VISION_MOCK=1` 时用内置样例数据走完整流程（卡片会标「模拟数据」），不花钱、不联网也能演示和回归界面。

重启 `npm run dev`，上传海报后右栏会出现「让模型先读一遍（可选）」。规矩是：

- key 只在 Node 侧（`/api/llm` 代理），浏览器和 `dist/` 里都看不到；
- 模型读到的每一项都带「原文片段 + 位置」，字段上标「模型读的」——**核过才算数**；
- 没有原文片段的降成「不太确定」，没有位置的标「无出处」；
- **不覆盖**你已经写下的东西；读到的碎信息会变成可点块（最多 6 个）。

额度用完时页面会直接说「账户额度不足（402）」，手动那条路照常。视觉链路只在 `npm run dev` 下可用。

## 活海报：把海报本身变成入口

1. 校样台右下「发出去 →」进入行动页，默认第一档就是**活海报**：原图铺满，图上被圈过的每一块都是虚线框。
2. 点任意一块 → 底部抽屉：这一块的放大图 + 原文 + 能做的事（时间→加日历，地点→三条导航，报名→链接，其余→复制或只是放大）。
3. 顶栏和抽屉里的动作都是真的：会下载 `.ics`、会打开地图、会复制到剪贴板。
4. 切到「文字版」还有四档读法（标准 / 大字 / 简明 / 结构化），给需要读长文字的人。
5. 分享链接 1.2KB 左右，二维码手机相机能扫；扫码打开的就是活海报，右上角可以切文字版。

**只圈不写也能发**：上传一张海报，一个字段都不填，只圈一块（比如「免费入场」），起个名、选「放大看」、写一句给观众的话，这个页面就能发出去。校样台底部的「发出去 →」会亮。

**发行前体检**：右栏顶部会列出跨字段矛盾和「手改过、和原文不一致」的地方，结论只有「可以发 / N 项会出事」。

## 行动页（P3）

1. 校样台右下「生成活动页 →」进入行动页（或直接访问 `#/` 后点它）。
2. 中间是手机预览，四档：**标准 / 大字（正文 22px、按钮 48px）/ 简明（只留时间·地点·怎么参加）/ 结构化（dt-dd 线性，给屏幕阅读器）**，换档立刻重排，同一份数据。
3. **加入手机日历**真的会下载 `.ics`（含 `Asia/Shanghai` 时区、全天与跨天都处理、75 字节折行）；另有 Google 日历链接兜底。
4. **导航到这里**给高德（国内最准）/ OpenStreetMap（不用登录）/ Apple 地图，搜索词是「场地 + 地址」，不假装知道门牌坐标。
5. 右栏是发出去的东西：**活动链接**（数据压进 URL hash，1.2KB）、**二维码**（手机相机扫开的就是整页活动）、复制链接、导出原始 JSON。
6. 扫码打开的是独立落地页：没有校样台外壳，末尾可展开「看看原海报」，让接收者也能核对。

边界：分享链接**不含海报图片**；`.ics` 只验证了文件内容，没在真机日历里导入过；二维码没被另一台手机实扫过。

## 明确没做的

- **自动识别**：`extract.ts` 里留了 `visionAdapter`，接视觉模型只改那一处；现在上传的图完全靠人拖框，不假装有 OCR。
- 上传自己的海报后**它也能生成活动页**，这部分还没做（等拖框标注接上）。
- 后端、账号、分享落地页：分享走 URL hash 自包含（`packDoc/shareUrl`），图片不带。
- 真实用户测试与准确率报告：`docs/验证记录.md` 还没开始（P5）。
